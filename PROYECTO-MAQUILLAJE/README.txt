TRUE BEAUTY — PROYECTO WEB EDITABLE

CÓMO ABRIR LA PÁGINA
1. Descomprime el archivo ZIP.
2. Entra a la carpeta HTML.
3. Abre index.html con doble clic. No necesitas instalar ningún programa.

CARPETAS
- HTML: contenido y textos de la página.
- STYLE: colores, tipografías, tamaños y apariencia.
- JAVA-SCRIPT: menú móvil, filtros, carrusel y animaciones.
- IMAGENES: fotos separadas en hero, productos, blog y logos.
- VIDEOS: espacio preparado para el video promocional.

CÓMO CAMBIAR UNA IMAGEN
Reemplaza el archivo dentro de IMAGENES conservando exactamente el mismo nombre y extensión. Así no tendrás que modificar el código.

CÓMO CAMBIAR EL LOGO DE TRUE BEAUTY
Reemplaza IMAGENES/logos/logo-true-beauty.svg. Si usas PNG o JPG, cambia también la extensión en las dos apariciones del logo dentro de HTML/index.html.

CÓMO CAMBIAR EL LOGO DE SELENIOS STUDIOS
Reemplaza IMAGENES/logos/logo-selenios.svg. El crédito se encuentra al final de HTML/index.html.

CÓMO CAMBIAR COLORES
Abre STYLE/style.css. Las primeras líneas contienen las variables --vino, --dorado, --blanco y demás colores principales.

CÓMO CAMBIAR PRODUCTOS O ARTÍCULOS
Abre HTML/index.html. Encontrarás comentarios que señalan las secciones CATÁLOGO y BLOG. Puedes editar nombres, precios, descripciones y fechas allí.

VIDEO PROMOCIONAL
Lee VIDEOS/videos-promocionales/LEEME.txt para activarlo.
